# Unit Converter

Convert between units instantly — length, weight, temperature, volume, speed, data, time. No model, no download.

Part of [FreeAgentStore](https://freeagentstore.online) — AI tools that run free in your browser.

## Install

```bash
npm install @freeagentstore/unit-converter
```

```ts
export { convert, getCategories } from "@freeagentstore/unit-converter";
```
